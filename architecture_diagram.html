2. Dev/Build Architecture

How the Python setup code generates the runtime objects. Run via workspace_main.py or the workspace_setup.ipynb notebook.

Build Pipeline (9 Steps)

Code Module → Output Mapping

config.py
python/config.py
Drives: All naming (DATABASE, WAREHOUSES, schemas), company universe (DEMO_COMPANIES), portfolio definitions, scenario→requirement mappings, AI model choices, document type registry
data/structured.py
python/data/structured.py
Produces: All DIM_* tables, all FACT_* tables in CURATED (positions, transactions, ESG, attribution, compliance, cash, NAV, PE, credit), all V_* views. Uses raw SQL via session.sql().
data/market_data.py
python/data/market_data.py
Produces: All MARKET_DATA tables. Reads from SNOWFLAKE_PUBLIC_DATA_FREE (Cybersyn), transforms + materializes locally. Also runs AI_COMPLETE for NLP scores.
core/hydration_engine.py
python/core/hydration_engine.py
Reads: content_library/ templates (59 Markdown files with {{PLACEHOLDER}} tokens)
Produces: Hydrated documents written to RAW tables or rendered as PDFs. Deterministic — no LLM calls.
data/pipelines.py
python/data/pipelines.py
Produces: All stages, streams, tasks (pipeline DAGs), RAW tables, CORPUS tables. Uploads PDFs to stages. Uploads skill files to SKILL_STAGE with {{DATABASE}} substitution.
ai/semantic_views.py + yaml_loader.py
python/ai/semantic_view_definitions/*.yaml
Produces: 17 semantic views via SYSTEM$CREATE_SEMANTIC_VIEW_FROM_YAML. YAML files use {{DATABASE}} templates resolved at build time.
ai/cortex_search.py
python/ai/cortex_search.py
Produces: 16 Cortex Search services pointing at CORPUS tables. Uses async job submission (collect_nowait) for parallelism.
ai/agents/*.py
python/ai/agents/{pm_cockpit, research_copilot, ...}.py
Produces: 8 Cortex Agents via CREATE AGENT with inline YAML specs. Composed from helper functions in _common.py. Registered with Snowflake Intelligence.
ai/tools/*.py
python/ai/tools/{backtest, monte_carlo, attribution, ...}.py
Produces: 9 stored procedures + 4 UDFs via CREATE PROCEDURE/FUNCTION with inline Python handlers. Tool result tables in AI schema.
ai/proactive_insights.py + signal_store.py
python/ai/proactive_insights.py, ai/signal_store.py
Produces: FACT_PROACTIVE_INSIGHTS (morning briefings via DATA_AGENT_RUN), FACT_SIGNALS (AI-extracted investment signals), scheduled tasks for daily refresh.
